# 字導字演 SubTutor 下載

Windows 桌面版的安裝檔發布在 [Releases](https://github.com/kevintsai1202/subtutor-releases/releases)。

**系統需求：** Windows 10／11（64 位元）。Mac 版規劃中。

## 安裝

1. 到 [最新版本](https://github.com/kevintsai1202/subtutor-releases/releases/latest) 下載 `SubTutor_版本_x64-setup.exe`。
2. 執行安裝檔。安裝檔目前沒有程式碼簽章，Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
3. 開啟字導字演，到「設定 → 帳號」以 Google 帳號登入。

剪輯、匯入字幕與匯出不需要登入。AI 功能（產生逐字稿、LLM 校稿、語音替換、智慧斷句）需要封測資格：到 [subtutor.zeabur.app](https://subtutor.zeabur.app) 登記，核准後自動開通。

## 更新

字導字演啟動時會自動檢查新版。有新版時畫面上方會出現通知，按「下載並更新」即可；安裝檔會先驗證簽章，裝完自動重新開啟。

## 功能建議

到 [subtutor.zeabur.app](https://subtutor.zeabur.app) 提出；已採用的建議在 [subtutor-feedback](https://github.com/kevintsai1202/subtutor-feedback) 追蹤。
